# Tools

A collection of interactive quantitative finance calculators and visualizers. Explore option pricing, portfolio risk, probability, statistical models, and more through a minimal interface. `index.html` is the GitHub Pages entry. Every tool opens on a synthetic worked example.

## Calculators

| Tool | Description |
|---|---|
| **Black-Scholes & Greeks** | Price European options and calculate Delta, Gamma, Vega, Theta, and Rho. |
| **Kelly Criterion Calculator** | Calculate the optimal bankroll allocation based on win probability and payoff odds. |
| **Position Size Calculator** | Determine position size from account equity, risk budget, and stop-loss distance. |
| **Options Payoff Builder** | Build option strategies and visualize profit, loss, and breakeven levels at expiry. |
| **Risk-Ratio Calculator** | Calculate annualized return, volatility, Sharpe ratio, Sortino ratio, maximum drawdown, and Calmar ratio from a return series. |
| **Drawdown & Recovery** | Calculate the return required to recover from a loss. |
| **Implied Volatility Solver** | Estimate implied volatility from an option's market price using the Black-Scholes model. |

## Visualizers

| Tool | Description |
|---|---|
| **Monte Carlo Simulator** | Simulate price paths using geometric Brownian motion and examine terminal-price distributions. |
| **Efficient Frontier Explorer** | Explore two-asset portfolio risk, return, correlation, and minimum-variance allocations. |
| **Central Limit Theorem** | Simulate sampling distributions across different source distributions and sample sizes. |
| **Overfitting Visualizer** | Compare training and test errors as polynomial model complexity increases. |
| **Distribution Explorer** | Explore normal, lognormal, exponential, Poisson, and binomial distributions. |
| **Regression Playground** | Add data points interactively and examine linear regression, residuals, and \(R^2\). |


## Disclaimer

For educational and research purposes only. Outputs depend on model assumptions and user-provided inputs and should not be treated as investment advice.
